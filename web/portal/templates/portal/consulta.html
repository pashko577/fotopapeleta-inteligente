Cómo se genera una papeleta

Evidencia trazable de principio a fin

  1. {% lucide "cctv" size=22 %}

    1. Detección

    Una cámara registra el vehículo y lee su placa con visión por computadora.

  2. {% lucide "waypoints" size=22 %}

    2. Análisis en la red

    El sistema busca la misma placa en otras cámaras y reconstruye la ruta.

  3. {% lucide "shield-check" size=22 %}

    3. Validación humana

    Un validador revisa la evidencia y aprueba o rechaza la infracción.

  4. {% lucide "file-check" size=22 %}

    4. Emisión y consulta

    La papeleta se emite y queda disponible aquí con toda su evidencia.
